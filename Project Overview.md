## Project Overview

In this project, you will simulate a real-world AI red team engagement against a machine learning system.

You will execute and analyze **five distinct attack classes**:

1. White-box adversarial evasion (FGSM)
2. Black-box evasion via transferability
3. Data poisoning via label flipping
4. Model extraction (optional stretch goal)
5. Supply chain vulnerability analysis (container security)

These attacks represent different layers of the AI threat surface:
- Model behavior manipulation
- Training data compromise
- System-level and infrastructure risk

You will document your findings in a structured red team report and provide evidence for each attack.
