# Starter Repository

Students complete five attack paths:
1. FGSM evasion against a custom CNN
2. Label-flipping data poisoning
3. Prompt injection
4. RAG data exfiltration
5. Supply-chain vulnerability analysis

Deliverables:
- Red Team Charter
- Vulnerability Report
- Executive Risk Summary
- Prompt Injection Transcript
- Poisoning Results
- Reproduction Steps
